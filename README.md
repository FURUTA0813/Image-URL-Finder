# Image URL Finder

Webページ上の画像・動画をクリックして、画像URLや動画URLをブラウザーの開発者ツールのコンソールに表示するシンプルなスクリプトです。

リンクが設定された画像をクリックした場合も、通常のリンク移動を防ぎます。

## 使い方

1. `image-url-finder.js` を開き、コードをすべてコピーします。
2. URLを調べたいWebページを開きます。
3. 開発者ツールを開きます（Windowsなら通常 `F12`）。
4. **Console（コンソール）** にコードを貼り付けて実行します。
5. ページ上の画像や動画をクリックします。
6. URLがコンソールに表示されます。

## 取得できるもの

- `img` 要素の画像URL（表示に使われている `currentSrc` を優先）
- CSSの背景画像URL
- `video` 要素の動画URLとポスター画像URL

## 注意

- URLはクリップボードにはコピーされず、コンソールに表示されます。
- ページを再読み込みするとスクリプトのクリック監視は終了します。
- サイト独自のJavaScriptによる画面遷移や、特殊な表示方式の画像では、リンク移動を完全に止められない場合があります。
- このスクリプトは、アクセス権のあるページで利用してください。表示されたURLへのアクセスや再利用には、各サイトの利用規約・著作権・アクセス制限が適用されます。

## 配布

このリポジトリの `image-url-finder.js` をダウンロードして利用できます。
